# Farmacia S.A. - ERP Financiero Cloud

Sistema integrado de contabilidad, finanzas, presupuestos, predicciones, caja, nómina y control ejecutivo.

## 🚀 Despliegue en Vercel

La app está lista para subir a Vercel. Solo sigue estos pasos:

1. Ve a https://vercel.com
2. Inicia sesión o crea cuenta
3. Click en "New Project"
4. Importa este repositorio de GitHub
5. Vercel detectará automáticamente que es Next.js
6. Click en "Deploy"

**¡Listo! Tu app estará online en 2-3 minutos.**

## 📊 Módulos

- **Contabilidad:** Plan de cuentas, asientos, balances
- **Compras:** Órdenes, proveedores, pagos
- **Ventas:** Facturas, clientes, cobros
- **Caja:** Movimientos, arqueo, control
- **Presupuestos:** Planificación y seguimiento
- **Predicciones:** Forecast financiero
- **Nómina:** Pagos, deducciones, reportes
- **Reportes:** Indicadores, estado financiero
